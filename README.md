# AeroCV Trading

Tablero de seguimiento del sector aeroespacial y defensa: puntajes de
rentabilidad a largo, mediano y corto plazo, senales de tendencia y flujo de
volumen sobre una lista de acciones y ETFs.

**No contiene datos de cartera personal.** Los montos, posiciones y precios de
compra no se publican aqui.

No es una recomendacion de inversion. Mide lo que ya paso en precio y volumen:
no considera valoracion, resultados, contratos ni riesgo regulatorio.
